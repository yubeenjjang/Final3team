# Infra

놀다가의 실행·배포 환경을 준비하는 폴더입니다.
신유빈이 주로 취합하고, 한태경이 설정·기동·검증을 지원합니다.

| 폴더 | 역할 |
| --- | --- |
| `database/` | PostgreSQL·pgvector 실행 및 DB 환경 설정 |
| `redis/` | Celery 작업 큐와 채팅 등에 사용할 Redis 환경 설정 |
| `deployment/` | 서버 배포·재시작·복구 관련 설정과 절차 |

현재는 폴더만 준비되어 있습니다. Docker 설정 파일과 실제 실행 방법은 인프라 작업을 시작할 때 추가합니다.
