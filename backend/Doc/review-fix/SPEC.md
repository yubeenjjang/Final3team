# review-fix 명세

- A77 조회·처리는 operator·admin이 할 수 있습니다. `block_user`는 대상의 `profiles.role`이 `user`일 때만 계정을 정지합니다. 운영자·관리자 정지 요청은 `403 FORBIDDEN`이며 계정과 신고 상태를 유지합니다. 모의 가입 계정은 모두 일반 사용자입니다.
- A06-2 로그인 스트림의 기한은 Access JWT의 `exp`입니다. WebSocket의 세션 유효성 함수로 진행·답변·종료 이벤트 전 폐기된 jti와 비활성 계정을 검사합니다. A06에 만료된 경로 조회 토큰을 보내면 `401 UNAUTHORIZED`로 응답합니다.
- DB 7-0 일일 작업에서 Refresh 토큰은 만료·폐기 중 늦은 시각 이후 7일, 실시간 스냅샷은 수신 후 7일에 삭제합니다. 경로 캐시 메타, 축제 추세, 라이브 지표는 각각 생성·수집·집계 창 이후 30일에 삭제합니다. 사건에 별도로 저장된 지표와 부하 시험 구간은 유지합니다. 챗봇·방문 코스 본문은 접수 후 30일에 비우고 `purged_at`을 기록합니다. 반환 집계는 변경된 행 수입니다.
- 028은 경로 캐시 메타가 만료되면 이를 참조하던 경로 결과의 `cache_key`를 NULL로 바꿉니다. 021을 되돌리면 020의 동행 채팅 RLS가 복원되어 읽기 전용 전환 후 정확히 72시간부터 메시지를 숨깁니다.
- A32·A78은 닉네임의 제어문자와 NUL을 거부합니다. 앞뒤 공백을 제거한 값으로 길이 2~12자와 중복을 검사합니다. 형식 오류는 `422 VALIDATION_ERROR`, 중복은 `409 NICKNAME_TAKEN`입니다.
- A04·A25는 공개 POST에 `rl:route` 메모리 카운터를 적용합니다. 기본값은 IP와 확인된 로그인 세션 각각 분당 10회입니다. `429 RATE_LIMITED`에는 `retryable=true`와 다음 분까지의 `Retry-After`를 담습니다. 제한은 공개 라우터에서 적용하므로 내부 서비스 호출에는 적용되지 않습니다.
- A69의 미지원 경로 동작은 `404 NOT_FOUND`입니다. A28은 TOPIS 고장 차량 코드 `A02`를 `accident`로 변환합니다.
- 한쪽이라도 차단했으면 A60 신청과 A62 승인을 `409 BLOCKED`로 거부합니다. A76에서 자기 계정을 신고하면 `400 VALIDATION_ERROR`로 거부합니다.

A32에 429가 명시되어 있으나 한도 설정은 A33에만 있습니다. API·DB 설계서에는 요청 범위의 `Cache-Control: private, no-store` 강제 조항이 없습니다.
