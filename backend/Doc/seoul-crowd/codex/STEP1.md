# Codex 작업 지시서 — W89 2단계 구현

11/23 권오현 결정은 [요청서](../REQUEST.md)에 기록합니다. [공통 규칙](_COMMON.md), [SPEC](../SPEC.md), [IMP-PLAN](../IMP-PLAN.md)을 따릅니다.

1. 기존 `find_festival` 조회와 공식 121개 구역의 경계 거리로 1km 이내 최대 3곳을 선택합니다. 서울 밖·좌표 없음·범위 밖은 사유를 구분합니다.
2. 서울시 인구데이터를 구역별로 호출하고 HTTP·본문·코드·시각·대체값을 검사합니다. 키는 로그와 오류에서 가립니다.
3. 60초 캐시·동시 요청 병합·KST 일일 호출 한도를 적용합니다.
4. 가까운 성공 구역은 기존 `areas[0]`에 넣고, 거리순 결과와 실패 상태는 `nearby_areas`로 제공합니다. 대체 평균을 표시하고 기존 모의 시나리오를 유지합니다.
5. 실제 모드 헤더와 하위 호환을 고정 파일과 가짜 전송으로 시험하고 백엔드 전체 시험을 실행합니다. API 설계문서 v0.4의 A10과 연동 현황을 갱신합니다.
