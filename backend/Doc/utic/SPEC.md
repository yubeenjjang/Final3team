# A28 UTIC 백그라운드 갱신

- `UTIC_ENABLED`는 기본값이 `false`입니다. 학원 허용망에서 별도 환경 변수 `UTIC_API_KEY`를 주입하고 `UTIC_ENABLED=true`로 설정합니다.
- 활성화하면 API 프로세스마다 lifespan에서 작업 하나가 즉시 전국 목록을 수집합니다. 다음 수집은 이전 시도 시작부터 기본 60초 뒤에 실행합니다. `UTIC_REFRESH_S`로 주기를, `UTIC_TIMEOUT_S`로 UTIC HTTP 호출 제한(기본 20초)을 설정합니다. 두 값은 양의 유한한 초 단위 값이며 유효하지 않으면 기본값을 사용합니다.
- 성공 시 정규화한 전국 목록과 관측 시각으로 보관본을 교체합니다. 빈 목록도 성공이면 보관합니다. 실패 시 마지막 성공본을 유지하고 다음 주기에 다시 시도합니다. 연속 실패의 첫 시도에서 고정 경고 한 줄을 남깁니다. 앱 종료 시 실행 중인 작업을 취소하고 종료를 기다립니다.
- A28은 UTIC 보관본을 읽으며 관측 시각이 `2 × INCIDENT_TTL_S`(현재 120초)를 넘으면 응답에서 제외합니다. 첫 수집 전과 만료 후에 다른 전국 공급원의 결과가 없고 TOPIS만 성공하면 기존 `seoul_only` 범위와 “전국 교통 돌발을 확인할 수 없어 서울 TOPIS 정보만 표시해요.” 안내를 사용합니다.
- API 워커가 여러 프로세스면 각 워커가 독립적으로 수집하고 자체 메모리 보관본을 사용합니다. 워커 수에 따라 UTIC 호출 수가 늘고 워커별 관측 시각이 다를 수 있습니다.
