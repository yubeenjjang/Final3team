# Codex 작업 지시서 — STEP3 막차 처리

1. API 설계서 5절·오류표·17-3절을 합성 예시와 `tests/routes/fixtures/`에 대조한다. 필드 근거와 확인이 필요한 부분은 SPEC P13에 기록한다.
2. SPEC P13~P15 및 IMP-PLAN의 STEP3 범위에 따라 TMAP 후보 필터와 전부 종료 응답, 카카오의 `null` 및 안내를 구현한다.
3. 기존 합성 고정 파일과 MockTransport로 정상·일부 종료·전부 종료·카카오 동기 결과 및 재조회를 시험한다. 저장소 루트에서 `_COMMON.md`의 공통 명령으로 전체를 실행한다.
4. API 설계서와 연동 현황표를 갱신하고 시험 결과를 기록한다. 실제 키·네트워크·커밋·푸시는 사용하지 않는다.
