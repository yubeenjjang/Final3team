## 원본을 넣지 않은 것

| API | 이유 | 대신 넣은 것 |
|---|---|---|
| TMAP 대중교통 | 약관: 받은 데이터는 저장 후 24시간 이상 사용 불가 | 합성 예시, 호출 기록 |
| 카카오 대중교통·도보 경로 | 경로 응답 저장 제한 | 합성 예시, 호출 기록 |
| 카카오 장소 검색 | 카카오 응답 저장 조건 미확인 | `_호출요약.json`의 건수(광화문 음식점 1,961건, 부산역 672건) |

**합성 예시**는 실제 응답의 구조와 필드 이름만 본뜬 데이터입니다. 좌표는 일정량 옮겼고, 정류장·노선 이름과 ID는 예시 값으로 바꿨으며, 경로는 첫 번째 것만 남겼습니다. 실제 경로가 아닙니다.

## 키 안전

- 저장소의 어떤 파일에도 인증키가 없습니다. 도구는 키를 화면에서 입력받아 메모리에서만 쓰고, 응답에 키가 섞이면 `{KEY}`로 바꿔 저장합니다.
- 올리기 전에 알려진 키 일부와 `serviceKey=`·`apiKey=`·`appKey`·`KakaoAK` 뒤의 실제 값이 없는지 검사했습니다.

## 다시 호출하려면

```bash
python3 scripts/noldaga_api_test.py
```

1. 브라우저에 열린 페이지에 각 사이트 키를 넣고 순위를 골라 실행합니다.
2. 결과는 `scripts/결과/`에 `YYYY-MM-DD_<api>_<조건>.json`으로 저장됩니다.
3. TMAP은 무료 한도(하루 10건) 보호를 위해 정상 호출한 항목을 같은 날 다시 부르지 않습니다.
4. TMAP·카카오 경로 원본은 저장 후 23시간이 지나면 자동으로 지웁니다.
