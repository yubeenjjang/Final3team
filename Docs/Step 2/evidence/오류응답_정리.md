# 외부 API 오류 응답 정리

> 2026-11-19~20 정리. **확인**은 테스트 도구로 실제 받은 응답, **문서 기준(미확인)**은 공식 문서에 적힌 내용이며 직접 재현하지 않았습니다. 응답 예시의 키 값은 `{KEY}`로 가렸습니다.

## TMAP 대중교통 (`POST https://apis.openapi.sk.com/transit/routes`)

| 경우 | HTTP | 응답 모양 | 근거 |
|---|---|---|---|
| 키 오류 | 403 | `{"error": {"id": "403", "category": "gw", "code": "INVALID_API_KEY", "message": "Forbidden"}}` | **확인** (11/19 16:53) |
| 경로 없음(출발·도착이 가까움 11, 출발 정류장 없음 12, 도착 정류장 없음 13, 기타 14) | **200** | `{"result": {"status": 14, "message": "검색 결과가 없음"}}` | 문서 기준(미확인) |
| 입력 오류(형식·범위 21, 필수값 누락 22, **서비스 지역 아님 23**, 타임머신 시각 오류 24) | 400 | `{"result": {"status": 21, "message": "..."}}` | 문서 기준(미확인) |
| 서버 오류(응답 없음 31, 기타 32) | 500 | `{"result": {"status": 31, "message": "일정 시간 응답이 없음"}}` | 문서 기준(미확인) |
| 무료 한도 초과 | — | 공식 문서에서 찾지 못함 | **미확인** |

- 경로가 없을 때도 **HTTP 200**이 오므로, HTTP 상태만 보면 안 되고 `result.status`가 있는지 확인해야 합니다.
- 키 오류는 SK open API 게이트웨이(`category: gw`)에서 막히는 형태라, 경로 탐색 오류(`result.status`)와 모양이 다릅니다.
- 출처: TMAP 대중교통 API 개발가이드 [대중교통 API 문서](https://transit.tmapmobility.com/docs/routes)(Error code index), [이용절차](https://transit.tmapmobility.com/guide/procedure)(에러 처리 예시)

## 카카오 대중교통·도보 (`GET https://dapi.kakao.com/v2/routing/publictraffic`, `/v2/routing/walk`)

| 경우 | HTTP | 응답 모양 | 근거 |
|---|---|---|---|
| 키 형식 오류 | 401 | `{"errorType": "AccessDeniedError", "message": "wrong appKey({KEY}) format"}` | **확인** (11/19 17:23) |
| 인증 헤더 없음 | 401 | `{"errorType": "AccessDeniedError", "message": "cannot find Authorization : KakaoAK header"}` | **확인** (11/19, 키 없이 시험) |
| 무료 쿼터 초과 | 400 | `{"code": -10, "msg": "API limit has been exceeded."}` | 문서 기준(미확인) |
| 대중교통 경로 결과 상태 | 문서에 없음 | `status`: `OK`, `STARTNODES_NULL`(출발지 노드 없음), `ENDNODES_NULL`, `EQUAL_POINTS`, `INVALID_REQUEST`, `NO_RESULTS` | 문서 기준(미확인). `routes`는 `OK`일 때만 옴 |
| 도보 경로 결과 상태 | 문서에 없음 | `status`: `OK`, `SAME_POINT`, `START_LINK_NOT_FOUND`, `END_LINK_NOT_FOUND`, `TOO_MANY_SEARCH_LINK`, `TOO_FAR_AWAY`, `ROUTE_RESULT_NOT_FOUND` | 문서 기준(미확인) |

- 쿼터 사용량은 카카오 앱 관리 페이지 **[통계] > [쿼터]** 에서 확인합니다.
- 출처: 카카오 개발자 문서 [카카오맵 REST API](https://developers.kakao.com/docs/latest/ko/kakaomap/rest-api), [카카오맵 공통 FAQ](https://developers.kakao.com/docs/latest/ko/kakaomap/common), [REST API 레퍼런스](https://developers.kakao.com/docs/latest/ko/rest-api/reference)

| 공공데이터포털(`apis.data.go.kr`, 표준데이터 포함) | 403 | `{"OpenAPI_ServiceResponse": {"cmmMsgHeader": {"errMsg": "SERVICE_KEY_IS_NOT_REGISTERED_ERROR", "returnAuthMsg": "등록되지 않은 서비스키", "returnReasonCode": "30"}}}` | **확인** |
| 공공데이터포털 일일 한도 초과 | — | `errMsg`: `LIMITED_NUMBER_OF_SERVICE_REQUESTS_EXCEEDS_ERROR` | 호출 가이드 기준(미확인) |
| 서울 버스도착정보(`ws.bus.go.kr`) | 401 | `{"error": "Unauthorized", "message": "유효하지 않은 서비스키입니다: 등록되지 않은 서비스키", "status": 401}` | **확인** |
| 서울 열린데이터광장 | 200 | `RESULT.CODE`=`INFO-100`(인증키 오류), 없는 장소는 `ERROR-500` | **확인** |

| 경찰청 돌발(UTIC) | 200 | `[{"resultCode": "02", "resultMsg": "유효한 KEY값이 아닙니다."}]` | **확인** |
| TAGO 정류소 | 200 | `{"response": {"header": {"resultCode": 99, "resultMsg": "가용한 세션이 존재하지 않습니다. (30/30)"}}}` | **확인**(서버 동시 접속 한도, 재시도로 해결) |
