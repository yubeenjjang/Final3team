- NAVER 검색의 블로그·뉴스·카페는 사용량·한도가 **한 줄로 묶여** 표시됨(뉴스·카페 행에는 별도 사용량 칸이 없음). 세 API 호출이 같은 한도에서 합산되는 것으로 보이며, 콘솔 안내로 따로 확인하지는 않음
- 위 한도는 "한도 및 알림" 설정 창의 **입력 가능 최대값**("1 부터 25,000 까지", "1 부터 775,000 까지", "1 부터 50,000 까지")이며, 현재 설정도 최대값. 사용량 90% 이상부터 10%마다 알림이 켜져 있음
- Data Lab 검색어트렌드 설정 창에는 월별 한도만 있고 일별 한도 항목이 없음
- 화면 안내
  - "한도 설정 기능은 고객의 편의 기능이며, 설정이 적용되는 동안 수초 내에 한도를 초과하여 호출할 수 있습니다."
  - "사용량은 과금단위로 적용됩니다."
- 요금: 이번 확인 화면(Application, Subscription)에는 단가가 표시되지 않았고, 콘솔 대시보드의 결제 정보는 "결제 내역이 없습니다". 유료 여부·단가는 별도 확인 필요
- 인증 정보(Client ID·Secret)는 열지 않았고 기록하지 않음
