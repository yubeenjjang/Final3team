# agy 작업 지시서 — 2단계 수정 (Claude 화면 확인에서 발견)

규칙은 `frontend/Doc/agy/_COMMON.md`. 아래 4가지만 고친다(2단계 파일 + `next.config.ts` 안에서만).

1. **이미지 불러오기 실패 처리(버그):** 이미지 주소가 404 등으로 실패하면 깨진 그림과 alt 글자가 보인다(모의 이미지 주소는 실제로 없음). 실패하면(`onError`) 이미지가 없을 때와 같은 "이미지 준비 중" 기본 화면으로 바꾸고, 그때는 "출처: 한국관광공사" 표시도 숨긴다. 목록 카드와 상세 큰 이미지 모두. 단위 시험 추가(`F6 image error fallback`).
2. **시각을 한국 시간으로(버그):** 날씨 관측 시각이 `11:00+09:00`인데 화면에 `02:00`, 공지 적용 기간도 9시간 앞당겨 보인다(UTC로 표시됨). 시각 표시는 모두 `Intl.DateTimeFormat`의 `timeZone: "Asia/Seoul"`로 고정하는 공통 함수 하나로 바꾼다(서버·브라우저 시간대와 상관없이 같게). 단위 시험: `"2026-11-22T11:00:00+09:00"` → `"11.22 11:00"`, `"2026-11-20T18:00:00+09:00"` → `"11.20 18:00"`.
3. **상세 정보 칩의 기간이 잘림:** `2026.11.20 ~ 2026.1…`처럼 말줄임됨 → 두 줄까지 줄바꿈 허용(말줄임 없이).
4. **개발 도구 표시:** 오른쪽 위로 옮겼더니 헤더의 로그인 아이콘을 가림 → `next.config.ts`에서 `devIndicators: false`로 끈다.

끝나면 공통 확인 명령이 통과하는지 보고 멈춘다(commit하지 않음).
