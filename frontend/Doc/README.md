# 프론트엔드 문서 안내

## 최신 기준 문서 (2026-11-25)

아래 네 문서가 현재 프론트엔드의 제품·디자인·구현·API 연동 기준이다.

1. `FRONTEND-PLAN.md` — 기능 범위와 사용자 흐름
2. `UI-DESIGN-SYSTEM.md` — 색상·반응형·이미지 규격
3. `FRONTEND-IMP-PLAN.md` — 최신 요구사항 기준 작업 분해
4. `API-INTEGRATION.md` — API 연동 및 상태 처리

핵심 확정 사항:

- 브랜드 기본색은 `#F74F85`다.
- 축제 포스터·썸네일은 가로:세로 `1:1.414`다.
- 지도에 표시되는 주변 환경·시설 이미지는 축제 포스터 규격을 재사용하지 않고 가로형 썸네일을 사용한다.
- 축제 찜·좋아요 기능을 제공한다. 카드와 상세에서 같은 찜 상태를 사용하고, 로그인 사용자는 마이페이지에서 찜한 축제를 확인할 수 있다.
- 알림·소셜 로그인 기능은 프론트엔드 범위에서 제외한다.
- 현재 저장소의 기술 스택은 Next.js App Router + TypeScript + Tailwind CSS다.
