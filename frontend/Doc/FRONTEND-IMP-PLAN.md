## 0. 작성 원칙

- 이 문서는 개발자가 실제 작업 순서에 따라 진행 상황을 체크하는 **프론트엔드 WBS 보조 문서**다.
- 이 표는 11/25 최신 요구사항을 기준으로 기존 구현을 다시 대조하는 작업 목록이다. 기존 완료 기록은 `IMP-PLAN.md`에 보존하며, 각 항목은 코드·시험 증빙을 다시 확인한 뒤 상태를 갱신한다.
- 단계별로 **선행조건, 산출물, 수용 기준, 확인 담당**을 명시한다.
- 일정은 팀 WBS 및 11/24 백엔드 요청에 근거한 **목표**이며, 해당 날짜까지 완료됐다는 뜻이 아니다.
- 화면/API 계약이 확인되지 않으면 더미 데이터로 UI 상태를 구현하되, 실제 연동 완료로 표시하지 않는다.

## 3. 권장 구현 순서 — 화면 우선 vs API 우선

**화면 1개씩 다음 순서로 완성한다.**

1. **정적 레이아웃**: 디자인 기준 390px에서 구조 완성
2. **재사용 컴포넌트화**: 카드·헤더·귀가 배너·빈 상태 공통화
3. **모의 응답 상태**: 성공/빈값/처리중/실패를 fixture로 재현
4. **계약 연결**: API 필드 이름·null·형식 확인 후 내부 응답 어댑터 작성
5. **실제 호출 및 오류 처리**: 네트워크·인증·재시도·중복 요청 방지
6. **반응형/접근성**: 좁은 모바일, 태블릿, 키보드, 터치 확인
7. **검증**: API 응답 + 실제 기기 스크린샷 + PR 리뷰

### 공통 컴포넌트 인터페이스 초안

```ts
// 인터페이스는 예시이며 실제 API 타입과 독립된 UI 모델이다.
type FestivalCardProps = {
  id: string;
  title: string;
  posterUrl: string | null;
  startDate: string | null;
  endDate: string | null;
  region: string;
  dDay?: number | null;
  onOpen: (festivalId: string) => void;
};

type AsyncViewState = 'idle' | 'loading' | 'success' | 'empty' | 'error';
```

- `FestivalCard`에 `favorite`, `isLiked`, `onHeartClick` 등을 추가하지 않는다.
- `aspect-ratio: 1 / 1.414`는 이미지 요소에 적용, 카드 수는 캐러셀 컨테이너에서 제어.
- `SafeReturnBanner`는 홈/상세에서 동일 컴포넌트 사용.

## 5. 화면별 최소 테스트 케이스

### 축제 카드/검색
- [ ] 390px에서 정확히 **3장+다음 카드 약 반 장** 보임
- [ ] 축제 카드 비율 정확히 **1:1.414**, 원본 사진 왜곡 없음
- [ ] 2줄 제목, 긴 이름일 때만 말줄임, 날짜/지역 충돌 없음
- [ ] 축제 사진 `null` → 기본 이미지 + 문구
- [ ] 0건 응답과 404를 서로 구분하여 안내
- [ ] 포스터에 **하트/찜 동작 없음**

### 축제 상세/혼잡
- [ ] 데이터 없을 때 프로그램·해시태그 영역 숨김
- [ ] 혼잡 4단계 원문/색 매핑, **퍼센트 없음**
- [ ] `nearby_areas` 0~3개, 거리 0m 포함 정상 표시
- [ ] `observed_at` 사용자 KST 표시, 45분 초과 오래됨 문구
- [ ] 서울 외 `unsupported`로 정보 없음, 임의 혼잡 수치 금지

### 귀가
- [ ] 202 `queued`/`processing`에서 후보를 미리 보여 주지 않음
- [ ] ready/빈 후보/unavailable/timed_out/rejected 분리
- [ ] `ROUTE_NO_RESULT`: 운행 종료 노선으로 결과 없음 안내
- [ ] Kakao 대체 시 `service_running: null`: 막차 확인 불가
- [ ] TMAP 경로를 Kakao 지도에 그릴 때 **출처 표시**
- [ ] 공식 통제와 충돌하는 후보 제외/검증 불가 경고

### 인증·공통
- [ ] 회원가입·로그인에서 간편/소셜 버튼 없음
- [ ] 토큰 만료/권한 부족/429/503/네트워크 종료 상태 확인
- [ ] 프로필 사진 업로드·알림 설정·찜 목록 없음
- [ ] 하단 5탭 모두 동일 아이콘·순서

## 6. 시연 체크리스트 및 API 연결 게이트

**12/8 시연 준비에 필요한 가장 작은 완성 단위**

- [ ] 홈페이지에서 축제 클릭 → 상세 정보 실제 데이터 또는 `is_mock` 표시
- [ ] 혼잡: 실데이터/오래됨/서울 외 데이터 없음 각 1회 시연
- [ ] 'AI 안심귀가' 배너 → 목적지 설정 → `POST A04`
- [ ] `202` 응답 → `GET A05` 폴링 → 성공 또는 제한/실패 안내
- [ ] 데이터 출처·관측 시각 표시, 오류 시 공식 안내 동선
- [ ] API 500·429 등 오류 주입 시 UI가 멈추지 않음
- [ ] 모바일 390px에서 중요한 텍스트 잘림 없음

**개발 완료 승인을 위한 증빙**: 관련 커밋/PR, API 응답 JSON(민감 값 제거), 테스트 결과, 화면 캡처, 검토자 승인. 담당자가 직접 확인하지 않은 작업은 `DONE` 처리하지 않는다.
