| 항목 | 값 |
|---|---|
| 브랜드 핑크 | `#F74F85` |

| 기본 배경 | `#FFFFFF` |
| 모바일 기준 폭 | 390 CSS px |
| 하단 메뉴 | 홈 / 축제 / 동행 / 귀가 / 지도 |

과거 `#F0145F`, 보라·네온 라임, 검정·노랑 홈 테마는 최신 기준이 아니다.

## 2. 이미지 규격

- 축제 포스터·축제 카드 썸네일: 가로:세로 `1:1.414`.
- 목록 썸네일은 세로 프레임을 채우도록 `object-fit: cover`로 중앙 크롭하고, 상세 공식 포스터는 `contain`으로 원본을 보호한다.
- 390px 축제 캐러셀은 카드 2개와 다음 카드 약 반 개가 보이도록 한다.
- 축제 카드 제목은 최대 2줄이다.
- 지도 주변 환경·시설 썸네일은 축제 포스터 비율을 적용하지 않는다. 가로형 이미지 영역과 `object-fit: cover`를 기본으로 하며 실제 원본·컴포넌트 요구에 맞춘다.
